## 📂 Structure

| Folder | What goes in there |
| :-- | :-- |
| [`📦 projects/`](projects/) | Complete programs and apps – one subfolder per project |
| [`⚙️ scripts/`](scripts/) | Small tools, automations & one-file scripts (`.py`, `.ps1`, `.js`, …) |
| [`🌐 web/`](web/) | Websites, HTML pages & web apps |
| [`🎨 designs/`](designs/) | Images, logos, icons & graphics |
| [`📄 documents/`](documents/) | Texts, PDFs, Word files, notes & guides |
| [`🗃️ archive/`](archive/) | Old versions and stuff I no longer use |

---

## 🧭 Rules for keeping it clean

1. **One project = one folder** → e.g. `projects/my-cool-app/`
2. **Use clear names** → lowercase with dashes: `discord-bot`, not `Neuer Ordner (3)`
3. **Add a short `README.md`** to each project: what it is & how to start it
4. **Old versions go to** `archive/` instead of being deleted

```
un0yy-forge/
├── projects/
│   └── my-cool-app/
│       ├── README.md
│       └── ...
├── scripts/
├── web/
├── designs/
├── documents/
└── archive/
```

## ⬆️ How to add files

1. Open the folder you want on GitHub
2. Click **Add file → Upload files**
3. Drag & drop your files in
4. Click **Commit changes** ✅
